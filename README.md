## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Aditya5250/aditya-portfolio.git

# Navigate to project directory
cd aditya-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to explore locally.

---

## 📦 Production Build

```bash
npm run build
```

Generates an optimized bundle in `dist/` in under 600ms.
